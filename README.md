# Terralens

`terraria-harita.html`: Terraria dünya dosyalarını (.wld) tarayıcıda okuyup haritasını çizen, tek dosyalık ve internet gerektirmeyen bir araç.
Kötü biyomların (Corruption/Crimson) ve Hallow'un Jungle'a uzaklığını analiz eder.

Kullanım: dosyayı tarayıcıda açın, `.wld` dosyasını sürükleyip bırakın.

Test: `node test/sahte-wld-uret.js 800 300 deneme.wld` kodu sahte bir dünya üretir (yanına beklenen dizi özetlerini `.json` olarak yazar).
